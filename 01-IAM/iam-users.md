
# AWS IAM Users

## 1. Overview

AWS Identity and Access Management (IAM) is a service that helps securely control access to AWS resources.

IAM allows administrators to create and manage users, groups, roles, and permissions.

## 2. Objectives

- Understand AWS IAM users.
- Learn how to create and manage IAM users.
- Understand authentication and authorization.
- Learn how IAM helps secure AWS resources.

## 3. What is an IAM User?

An IAM user represents an individual person or application that needs access to AWS services.

Each IAM user can have specific permissions based on their responsibilities.

## 4. Key Activities

- Explored the AWS IAM dashboard.
- Learned about IAM users and their purpose.
- Understood how permissions control access to AWS services.
- Studied the importance of secure access management.

## 5. Security Best Practices

- Follow the principle of least privilege.
- Avoid sharing AWS credentials.
- Enable Multi-Factor Authentication (MFA).
- Use strong passwords.
- Review user permissions regularly.

## 6. Learning Outcome

Learned the fundamentals of AWS Identity and Access Management and how IAM users help manage secure access to cloud resources.
